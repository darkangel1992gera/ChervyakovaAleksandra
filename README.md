# Weather Diary (Дневник погоды)

**Автор:** Червякова Александра Павловна

## Описание
GUI-приложение для ведения дневника погоды. Позволяет добавлять записи с датой, температурой, описанием и признаком осадков. Реализована фильтрация по дате и минимальной температуре, сохранение данных в JSON-файл и загрузка из него.

## Как запустить приложение
1. Убедитесь, что у вас установлен Python 3.6 или новее.
2. Склонируйте репозиторий или скачайте файлы проекта.
3. Перейдите в папку проекта: `cd weather_diary`
4. Запустите программу: `python main.py`

## Примеры использования
- Введите дату в формате `дд.мм.гггг`, температуру (например, `-5.5`), описание (`Солнечно`) и отметьте осадки при необходимости.
- Нажмите «Добавить запись» – запись появится в таблице.
- Для фильтрации укажите дату или минимальную температуру и нажмите «Применить».
- Чтобы сбросить фильтры, нажмите «Сбросить».
- Используйте кнопки «Сохранить в JSON» и «Загрузить из JSON» для работы с файлом `weather_diary.json`.

## Возможные тесты
1. Попробуйте добавить запись с пустым описанием – появится сообщение об ошибке.
2. Введите неверную дату (например, `32.13.2025`) – программа сообщит о некорректном формате.
3. В поле температуры введите текст – будет показана ошибка.
4. Добавьте несколько записей, сохраните их, закройте приложение, откройте снова – данные загрузятся автоматически.
5. Примените фильтр по минимальной температуре `10` – отобразятся только записи с температурой >10°C.
